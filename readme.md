# 🚀 InsightGen AI – AI-Powered Data Analytics Assistant

## 📌 About the Project

**InsightGen AI** is an AI-powered data analytics web application that helps users analyze datasets, generate meaningful insights, and visualize data through interactive charts.

It simplifies data analysis by allowing users to ask questions in natural language without requiring advanced programming or data analytics knowledge.

## ✨ Key Features

- 📂 **Dataset Upload** – Upload CSV and Excel datasets for analysis.
- 🤖 **AI Assistant** – Ask questions about your data using natural language.
- 📊 **Data Visualization** – Generate bar, line, pie, scatter, and other charts.
- 💡 **Smart Insights** – Understand trends, patterns, and relationships in datasets.
- 🔐 **User Authentication** – Secure login using Google and email.
- 💬 **Chat History** – Save and revisit previous AI conversations.
- 🌙 **User-Friendly Interface** – Responsive dashboard with dark mode support.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| React.js & TypeScript | Frontend development |

| Tailwind CSS & shadcn/ui | UI design |
| Google Gemini API | AI-powered data analysis |
| Supabase | Authentication and database |
| Google OAuth | Google sign-in |
| Recharts | Data visualization |
| Vercel | Web application deployment |
| GitHub | Version control |

## 🚀 How to Use

1. Open the InsightGen AI web application.
2. **Sign up or log in** using Google or email.
3. **Upload a dataset** in CSV or Excel format.
4. **Select the dataset** you want to analyze.
5. **Ask the AI assistant** questions about your data.
6. **Explore insights and charts** generated by AI.
7. **Access chat history** to revisit previous analyses.

## 🎯 Project Objective

To make data analytics simple, accessible, and efficient by combining artificial intelligence, natural language processing, and interactive data visualization.
